# 花间日常 · Huajian Daily

一个可自行部署的双人生活记录网站。以牡丹粉、奶油白与蓝色点缀生活，
记录一餐一饭、照片、足迹、心愿和特别的日子。

[MIT 许可证](LICENSE) · [行为准则](CODE_OF_CONDUCT.md) · [参与贡献](CONTRIBUTING.md) · [安全说明](SECURITY.md)

此仓库只提供通用程序、部署配置与虚构示例，不包含维护者的私人照片、日记、联系方式、数据库或生产凭据。
项目没有提供公共数据托管服务；请部署自己的实例。

## 功能

- 共用密码进入；两台设备共享同一实例的数据。
- 日常发布与评论、最近发布动态、按设备选择记录人。
- 分类相册、保留原图、批量整理、EXIF 拍摄时间读取与日期排序。
- 支持部分内嵌 MP4 的实况 JPEG；旧照片可检测实况。
- 两人档案、餐食与忌口提示、足迹、纪念日、心愿、未来开启的信件。
- 私密手账、沟通复盘与约定。
- 连续 AI 对话、选择参考记录、经验证的记录新增与修改、操作确认。
- 原图 ZIP 备份、缺失记录合并恢复、30天回收站。
- 手机界面、牡丹动效、灵动/柔和/关闭选项与系统减少动态效果支持。

## 技术栈

React19、TypeScript、Vite、Node.js24、sharp。开发环境使用 SQLite 和本地文件，
Netlify 部署使用 Functions、Database 和 Blobs。两种运行环境的数据不会自动同步。

## 本地开发

```bash
npm ci
npm run dev
```

打开 `http://localhost:3000`。首次启动会生成本地访问密码，保存在本机
`.private/access.txt`；请在自己设备查看，不要提交或分享该文件。
本地持久化数据位于 `.private/data`，删除目录会丢失数据。
可以通过服务端环境变量 `SPACE_PASSWORD` 或 `SPACE_PASSWORD_HASH` 自行配置访问密码。
此开发启动器不应直接裸露在公网；正式环境需要 HTTPS 和安全 Cookie。

## 部署到 Netlify

1. Fork 本仓库，或将代码复制到自己的仓库。
2. 从 Git 仓库创建一个独立 Netlify 项目，保留 `netlify.toml`。
3. 构建命令为 `npm run build`，发布目录为 `dist`，Node.js版本为24。
4. 在本机生成密码哈希：

   ```bash
   npm run password:hash --silent
   ```

   命令从标准输入读取至少10个字符的密码；不要将明文密码写入命令行参数或日志。
5. 配置服务端变量 `SPACE_PASSWORD_HASH`，其作用范围必须包含 Functions；
   按平台支持设为秘密值。重新部署后生效。
6. Netlify Database 需在账号中可用，并应用 `netlify/database/migrations` 中的迁移；
   照片通过 Netlify Blobs 保存。平台资源、费用和额度以账号实际设置为准。
7. 先确认未登录时 `/api/bootstrap`、照片和评论接口拒绝访问，再导入自己的资料。

生产和预览环境的数据命名空间隔离。不要把私人导入文件、数据库、原图或备份放进 `public`、`dist` 或 Git。
请先在预览环境验证改动，再集中发布正式版，避免不必要的部署费用。

## 可选 AI

服务端配置 `CHATANYWHERE_API_KEY`，可选配置 `CHATANYWHERE_MODEL`（默认 `gpt-4o-mini`）
与 `CHATANYWHERE_BASE_URL`（默认 `https://api.chatanywhere.org/v1`）。仅接受代码允许的服务端接入点。
密钥不可放进前端、浏览器存储或公开仓库。

每个实例共用100次/日尝试额度，按北京时间零点重置；外部服务商另有额度，失败尝试也可能计次。
每次对话会发送本轮问题、最近最多8轮对话及本次主动选择的参考内容。
未到期的信件不进入模型上下文。单条普通新增/修改可自动执行；删除、批量、设置与敏感记录先确认。
AI 不拥有任意代码执行、认证配置修改或原图文件修改权限。

## 照片与排序

原图支持 JPEG、PNG、WebP，每张最多15 MiB。通过服务器解析 EXIF 原始拍摄时间，
保留相机本地时间，不猜时区、不根据文件名猜日期。转发图、截图可能没有 EXIF，
这时可手动补日期；未知拍摄时间暂用上传日期分组。旧照片需要在相册主动读取拍摄信息。

实况播放仅覆盖部分标准 XMP/旧版 MicroVideoOffset 格式，并依赖浏览器支持对应视频编码；
不支持所有厂商格式，也不提供 HEIC/MOV 配对转换。

## 备份与数据边界

完整 ZIP 包括原图、缩略图、记录、日常评论和回收站内容，可能包含未开启信件原文。
ZIP 未加密。AI 对话历史当前不包含在 ZIP 中，迁移时需另行处理。
备份需重新输入密码；浏览器/服务端存在文件大小与记录数量上限，超限时会停止并提示。
恢复会补充缺失内容，保留已有记录。回收站默认保留30天，定时清理需要部署环境支持计划任务。

发布提醒是网站内提示，页面可见时约每30秒检查；不提供关闭浏览器后的系统推送。
共用密码下的姓名选择是自我声明，不是个人身份认证。
